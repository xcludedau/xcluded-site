1. Create a new PUBLIC repository (e.g. xcluded-site) on GitHub.
2. Upload the CONTENTS of this folder to the repository root, not the ZIP itself.
3. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
4. Wait for the URL shown in GitHub Pages settings.
5. Check homepage, film, quote, enquiry, and mobile before sharing publicly.
6. Do not connect xcluded.com.au until VentraIP approves registration.
